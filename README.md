# If pages demo

3 toy examples of if pages.

What would happen depending on how these questions resolve:
- Will New York City experience a hurricane before 2030?
- What will the ENSO state be in June–August 2027: La Niña, neutral or El Niño?
- Will the UK vote to leave the EU in the 23 June 2016 referendum? (backtest demo)

Disclaimers:
- The issues are real, but the conditional probabilities are just here as examples, not as actual predictions.
- The starting consequences and interface was AI-generated.
